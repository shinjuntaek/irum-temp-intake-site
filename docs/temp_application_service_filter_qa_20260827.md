# 임시 관리자 신청 서비스 분류 QA

## 범위

`irum.click/admin/` 신청자 목록에 추가한 신청 서비스 분류 필터와 badge를 검증했습니다. 서비스 분류는 기존 Snapshot·임시 intake 원본을 수정하지 않고, 동일 전화번호의 1:1 매칭·프라이빗 소셜 신호를 읽어 `1:1 매칭`, `프라이빗 소셜`, `둘 다 신청`으로 계산합니다.

## Chromium fixture 결과

| 검증 항목 | 결과 |
|---|---|
| 1440px 데스크톱 필터 배치 | 검색·상담·발송·2차 신청·신청 서비스·보기 전환이 한 행에서 구분되어 표시됨 |
| 카드 badge | 1:1 매칭, 프라이빗 소셜, 둘 다 신청이 각각 별도 chip으로 표시됨 |
| `둘 다 신청` 필터 | `?service=both` URL 유지와 두 fixture 카드의 `both` badge를 확인함 |
| 390px 필터 배치 | 5개 필터가 두 열·세로 흐름으로 배치되고 가로 overflow 없음 (`390px = scrollWidth`) |
| 기존 기능 회귀 | 무인증 차단, 5영역 상세, private 사진·서류, 2차 링크/수동 발송, 모바일 메뉴, 소셜 일정 표시 통과 |

테스트 fixture 및 로컬 캡처는 운영 데이터와 분리되어 있으며, 운영 Snapshot·임시 접수·사진·2차 form은 수정하지 않았습니다.
