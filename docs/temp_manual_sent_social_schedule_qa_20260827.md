# 임시 관리자 수동 발송·소셜 일정 QA

## 시각 검수

- 데스크톱 신청자 목록에서 `상담 상태 전체`, `2차 링크 발송 전체`, `2차 신청 상태 전체`가 서로 독립된 select로 한 줄에 정렬되며 카드 영역과 겹치지 않는다.
- 소셜 신청 카드에는 `모임 일정 · 9월 19일`이 별도 행으로 보이며 기존 서비스·상담 정보와 중복되지 않는다.
- 390px 프라이빗 소셜 화면에 `소셜 신청자 선택 일정` 섹션이 추가되고 `8월 29일`, `9월 19일`, `다음 모임 희망`, `구형 일정 미수집` 집계 chip이 2열 responsive grid로 모두 잘림 없이 표시된다. 신청자별 일정 표도 가로 overflow 없이 유지된다.
- fixture에서 실제 신규 소셜 신청은 `9월 19일`, legacy 신청은 `구형 신청 · 일정 미수집`으로 구분된다.

## 기능 검증

- 수동 `2차 링크 발송 완료` 및 `발송 완료 취소`는 명시적 버튼 클릭과 확인창 이후에만 Edge action을 호출한다.
- 링크 재발급은 sent metadata를 null로 초기화한다.
- 링크 복사·열기 코드는 발송 완료 action을 호출하지 않는다.
- private 사진 1건, private 서류 1건, 5영역 단일 상세, 모바일 390px 가로 overflow 없음 계약을 함께 검증했다.
